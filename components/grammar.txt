<program>       :   { <statement> }
<statement>     :   <TT_IDENT> <TT_EQ> <expression>
                |   print <TT_LPAREN> <expression> <TT_RPAREN>
<expression>    :   <term> { (<TT_PLUS> | <TT_MINUS>) <term> }
<term>          :   <power> { (<TT_MULT> | <TT_DIV>) <power> }
<power>         :   <primary> [ <TT_POW> <power> ]
<primary>       :   <TT_NUMBER>
                |   <TT_IDENT>
                |   memory
                |   <TT_LPAREN> <expression> <TT_RPAREN>
